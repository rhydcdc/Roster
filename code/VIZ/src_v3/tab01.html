01 · 학습: 뉴런 출석부를 어떻게 만드나

이미 학습이 끝난 원본 모델에서 출발해, 입력이 모이는 구역(중심점)마다 켤 뉴런 목록(출석부)을 정하고, 모델을 그 목록에 맞게 다시 학습시킨다. 뉴런 8개짜리 예시 하나로 끝까지 따라간다.

먼저

작은 예시와 실제 모델의 대응

이 탭의 그림은 전부 왼쪽의 작은 예시이고, 실제 모델은 오른쪽 크기로 똑같이 돌아간다.

배경 1

출발점: 원본 모델과 교사 모델

처음부터 뉴런을 가리면서 배우면 성능이 무너진다. 그래서 사전학습이 끝난 원본 모델(뉴런 N1 ~ N8을 100% 다 켬)을 그대로 들고 시작한다. 원본 모델의 복사본 하나는 가중치를 고정해 교사 모델로 쓴다.

배경 2

토큰

모델의 한 층에 들어오는 데이터 1개다. 우리 실험에서는 사진 1장, LLM에서는 단어 토큰 1개다.

배경 3

2차원 좌표

토큰은 층에 들어올 때 숫자 묶음(벡터)으로 표현된다. 눈으로 보기 위해 (x, y) 좌표로 줄여서 본다. 실제는 1,024차원이다.

1단계

중심점 만들기 (k-means)

정답 라벨은 보지 않고 좌표 위치만으로, 비슷한 토큰끼리 4개 구역으로 나누고 구역마다 대표 좌표(중심점 A, B, C, D)를 뽑아 끝까지 고정한다.

이 그림의 좌표 (이름표가 붙은 토큰 8개와 고정된 중심점 4개)
  • 이름표가 붙은 토큰: T1 (1.0, 1.2) · T2 (1.2, 0.8) · T3 (2.2, 1.6) · T4 (2.0, 1.2) · T5 (-1.2, -1.0) · T6 (-1.0, -1.2) · T7 (-2.2, -0.6) · T8 (-2.0, -0.8)
  • 고정된 중심점: A (1.1, 1.0) ← T1, T2가 모임 · B (2.1, 1.4) ← T3, T4가 모임 · C (-1.1, -1.1) ← T5, T6이 모임 · D (-2.1, -0.7) ← T7, T8이 모임
  • 이름표가 없는 작은 점들은 되풀이 과정을 눈으로 보이려고 네 중심점 둘레에 지어낸 토큰이다. 그 위에서 k-means를 실제로 돌린 것을 그대로 보여 준다.
중심점은 라벨이 아니라 주소 번호다중심점은 특정 클래스가 아니라 입력 벡터 공간에서 비슷한 좌표가 모이는 구역의 대표점이다. 비지도 방식이라 클래스 라벨이 없는 LLM에도 그대로 적용된다. 새 토큰이 들어오면 신경망 라우터 없이, 고정된 중심점들과 거리만 한 번 재서 가장 가까운 중심점 방으로 배정한다. 4개 층이 저마다 자기 층의 입력 공간에 맞는 중심점을 따로 가진다.
실제 모델에서는앞 1 ~ 3층 중심점 32개4층 중심점 256개반복 40회

뉴런을 많이 켜서 전체 시간의 대부분을 차지하는 앞 1 ~ 3층은 중심점을 32개로 통합해 같은 방에 토큰이 많이 겹치게 하고, 이미 0.8%만 켜서 원래 빠른 4층은 256개의 세밀함을 살려 정확도를 지킨다.

2단계

중심점마다의 뉴런 출석부와 켜는 수 K

중심점마다 뉴런을 기여도가 큰 순서로 줄 세운 목록이 출석부다. 앞에서 몇 개까지 켤지(K)는 중심점마다 다르고 층마다도 다르다.

  1. 기여도를 잰다. 학습 토큰을 원본 모델(8개 다 켬)에 통과시키며 각 뉴런이 출력에 실제로 보탠 힘을 잰다.
    FFN 출력 = a1w1 + a2w2 + ⋯ + a8w8  →  뉴런 i의 기여도 = ‖aiwi‖2 = |ai| × ‖wi‖2
    활성값 ai와 W_down의 열 벡터 wi의 크기를 함께 반영한다.
  2. 줄을 세운다. 중심점 A에 배정된 토큰들이 뉴런마다 쓴 힘을 합산해 큰 순서대로 적는다. 이것이 그 중심점의 출석부다.
  3. K를 정한다. 허용 오차 ε(입실론)을 기준으로 "앞에서 몇 개까지만 켜도 원래 출력과의 오차가 ε 이하인가"를 재서 초기 K를 중심점마다 따로 정한다.
  • 가변 K: A는 6개, B는 5개, C는 4개, D는 3개로 중심점마다 켜는 개수가 다르다.
  • 같은 중심점 = 100% 같은 뉴런: 같은 중심점 A에 들어온 토큰들(T1, T2)은 토큰에 따라 K가 달라지지 않고 항상 똑같은 뉴런 집합을 켠다. 이것이 대형 배치에서 빈칸 없이 묶이는 기반이 된다.
  • 중복 공유 허용: MoE처럼 뉴런을 방으로 쪼개지 않고, A와 B가 N1, N2, N5, N7을 겹쳐서 같이 쓸 수 있다.
3단계

가족과 블록

가족은 쓰는 뉴런이 비슷한 중심점끼리의 묶음이고, 블록은 GPU가 한 번에 퍼 오는 나란한 뉴런 묶음이다. 둘 다 위 출석부 표에서 바로 나온다.

A가족: "쓰는 뉴런이 비슷하다"의 기준

중심점마다 뉴런 8개에 쏟은 힘의 분포(가로줄)를 나란히 놓고, 두 가로줄의 방향이 얼마나 닮았는지(코사인 유사도)를 잰다. 두 중심점을 골라 보자.

닮은 순서대로 중심점을 한 줄로 세운 뒤 균등하게 자른 묶음이 가족이다. 가족 1 = {중심점 A, 중심점 B}, 가족 2 = {중심점 C, 중심점 D}.

실제 모델에서는앞 3개 층: 중심점 32개를 4개씩 8가족4층: 16가족

벡터 내적 공식 그대로, 두 가로줄의 길이를 1로 맞춘 뒤 내적해 방향이 얼마나 같은지 잰다 (1에 가까울수록 비슷, 0에 가까울수록 딴판).

코사인 유사도(X, Y) = X · Y‖X‖2 ‖Y‖2
  • 각 중심점 벡터의 길이: ‖A‖2 = √(40² + 10² + 30² + 2² + 20² + 1² + 15² + 4²) = √3,246 ≈ 56.97 · ‖B‖2 = √3,198 ≈ 56.55 · ‖C‖2 = √3,575 ≈ 59.79 · ‖D‖2 = √3,147 ≈ 56.10
  • A 대 B (같은 가족): 내적 = 40×35 + 10×32 + 30×4 + 2×1 + 20×28 + 1×2 + 15×12 + 4×0 = 2,584 → 2,584 ÷ (56.97 × 56.55) ≈ 0.80 (매우 가까움)
  • A 대 C (다른 가족): 내적 = 40×2 + 10×1 + 30×6 + 2×40 + 20×3 + 1×36 + 15×2 + 4×25 = 576 → 576 ÷ (56.97 × 59.79) ≈ 0.17 (매우 멂)

B블록: 무엇이고 왜 필요한가

GPU 텐서 코어는 뉴런을 1개씩 따로 꺼내 계산하지 못한다. 메모리에 나란히 붙어 있는 뉴런 묶음(실제 GPU는 32열, 이 예시는 2열 = 1블록) 단위로 통째로 퍼 와서 행렬곱을 한다. 그래서 켜는 뉴런이 블록 안에 뭉쳐 있어야 한다.

학습 중에는 이 순서 목록으로만 묶어 계산하고, 실제 메모리의 물리 재배치는 학습이 끝난 5단계에서 딱 1번 한다. 순서만 바꾸는 것이므로 수학 계산 결과는 100% 같다.
4단계

사후학습(일 몰아주기) → K 조이기 → 반복

켜 둔 앞 K개 뉴런만 쓴 채 모델을 살짝 다시 학습시켜 일을 앞쪽 블록으로 몰고, 일이 빠진 꼬리 뉴런을 잘라 낸다. 이것을 9바퀴 되풀이한다.

학습 토큰이 들어오면 가장 가까운 중심점을 찾고, 그 중심점 출석부의 앞 K개 뉴런만 켜고(나머지는 0으로 막아 둔 채) 계산한다. 이 상태로 모델에게 두 가지를 시킨다.

요구 1

원래 성능 유지

"출석부에 적힌 앞 K개 뉴런만 켰지만, 분류 정답도 맞히고 각 층의 출력도 다 켠 교사 모델과 똑같이 내라."

요구 2

일 몰아주기 (벌점)

뒤쪽 뉴런과 가족이 덜 쓰는 블록에 벌점을 매겨, 일이 같은 가족이 함께 쓰는 앞쪽 블록으로 옮겨 가게 한다.

한 바퀴 동안

고정되는 것과 바뀌는 것

중심점 좌표, 출석부, K, 가족 소속은 고정이고 모델 가중치만 바뀐다. 앞 층 가중치가 바뀌어 다음 층 입력 좌표가 살짝 움직이면, 매 학습 걸음마다 현재 좌표에서 가장 가까운 중심점을 다시 찾는다.

K는 어떻게 조이나 (학습 없음, 허용 오차 ε 기준)

  1. 중심점마다 K 정하기: 앞 k개만 켠 FFN 출력과 자르기 직전 FFN 출력의 상대 오차가 허용 오차 ε 이하가 되는 가장 작은 k를 새 K로 잡는다.
  2. ε 값 고르기: ε 후보 여러 개(0.001, 0.003, 0.005, …)를 4개 층·모든 중심점에 똑같이 대입해 보고, 검증 데이터 정확도가 통과 문턱(90.96%) 이상을 지키는 선에서 평균 K가 가장 작아지는 ε을 자동으로 고른다.
  • 전체에 ε 하나만 걸어 두면 출력이 민감한 1·2층이나 복잡한 중심점은 알아서 K를 많이 남기고, 여유가 큰 4층이나 단순한 중심점은 알아서 K를 확 줄인다.
  • 한 번 꺼진 뉴런은 영구 탈락한다.

9바퀴가 끝나면 세 가지가 함께 달성된다

5단계

학습이 끝난 뒤 배포 준비 (학습 없음)

꼬리를 더 버려도 되는지 검증으로 확정하고, 가중치를 블록 순서대로 딱 한 번 옮겨 저장한다.

9바퀴가 끝나면 중심점 출석부에는 확정된 앞 K개 번호만 남고(그 뒤 뉴런은 그 중심점에서는 없는 것), N3처럼 모든 중심점에서 다 꺼진 뉴런만 모델 전체에서 한 번도 읽히지 않게 된다.

마무리 1

꼬리 생략(1*) 비율 확정: 0% (1개도 안 버림)

타일링할 때 자투리를 없애려고 출석부 끝쪽 뉴런 일부를 꺼도 되는지(1*) 검증 데이터로 확인한다. 이미 32개 중심점에 핵심 뉴런만 빽빽하게 압축돼 있어 0%가 유일하게 검증 문턱(90.96%)을 통과한다. 버리는 뉴런이 1개도 없으므로 단일 요청(B = 1)이든 대형 배치(B = 2,048)이든 수학적으로 100% 같은 출력이 나오고, 묶기 정확도 손실도 0.00%p다.

마무리 2

가중치 물리 재배치 (배포 때 1회)

확정된 블록(열) 순서대로 실제 모델 가중치(W_gate, W_up, W_down)를 메모리에서 딱 한 번 재배치해 저장한다. 실제 추론할 때 열 순서를 다시 섞는 비용은 0이다.
