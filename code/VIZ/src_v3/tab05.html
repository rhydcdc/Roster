기준 2

조합과 맞물림의 새로움

학습·구조·실시간 타일링·커널이 따로 노는 부품 나열이 아니라, 한 축이 만든 구조적 성질을 다음 축이 그대로 받아 시너지를 내는가?

1순위

실시간 비격자 5단계 타일링

구현한 선행 연구가 없고, 다른 연구진이 "가장 유망한 방향"이라며 향후 과제로 남겨 둔 문제를 실제로 풀어 실리콘에서 검증했다.

왜 1위인가Park 등(arXiv 2605.08575, 9쪽)은 "토큰과 뉴런을 하드웨어 폭에 맞춰 블록 단위로 묶는 것이 가장 유망한 방향"이라고 적고 향후 과제로만 남겨 두었다.

①같은 6 × 8 표 위의 대결: MatFormer 대 BSMR 대 우리 비격자

03에서 쓴 것과 완전히 같은 6토큰 × 8뉴런 표(1이 23칸, 밀도 47.9%) 위에 기존 계열과 우리 방식을 그대로 올려 본다.

②행 짝을 바꿔도 계산이 안 틀리고 충돌(atomicAdd)이 0인 까닭

  • 결과 불변성 (출력 변화 0%): 토큰과 뉴런이 원래 번호표를 그대로 달고 잠깐 같은 네모 틀에서 곱셈을 마친 뒤 자기 자리로 돌아갈 뿐이므로, 수식은 1비트도 바뀌지 않는다.
  • 일반 SpMM(GNN, 가중치 프루닝 등)은 왼쪽 입력 행렬에 0이 뚫려 있어, 한 행의 열을 두 틀로 쪼개면 두 GPU 팀이 똑같은 출력 방에 값을 동시에 더하려다 atomicAdd 충돌이 난다.
  • FFN 1단계(확장 · gate·up)는 오른쪽 출력 h에 0이 뚫려 있다(SDDMM 형태). 틀끼리 겹치는 칸이 0개이기만 하면 두 GPU 팀이 쓰는 메모리 방이 아예 다르므로, 틀마다 행 짝을 아무리 바꿔도 atomicAdd = 0이다.
  • FFN 2단계(축소 · down)는 1단계가 결과를 닮은 중심점 순서대로 바로 저장해 두고, 한 GPU 팀이 토큰 묶음(1 ~ 3층 32명, 4층 16명)을 처음부터 끝까지 전담 합산해 atomicAdd = 0과 합집합 16.1%를 함께 얻는다.

작은 숫자 행렬로 직접 눌러 보기 → 04의 FFN 1단계, 04의 FFN 2단계

③5단계 실측 비용 사다리와 46초 → 1.49 ~ 2.83 ms 실시간 타일링

  • 왜 5가지 틀 크기를 섞나: 큰 틀(64×32)은 한 번 긁어 와서 오래 연산해 긁어 오는 횟수를 크게 줄이지만, 큰 틀 하나만 쓰면 자투리에 ×0이 가득 낀다. 작은 틀(16×16 · 8×16) 하나만 쓰면 한 번 긁어 와서 연산하는 양이 4배 줄고 긁어 오는 횟수가 4배 늘어 칸당 GPU 비용이 2.31 ~ 3.90배 비싸진다. RTX 4060 실측 단가(1.00× / 1.22× / 1.52× / 2.31× / 3.90×) 순으로 사다리를 짜, B = 2,048에서 전체 연산의 76.7%를 최고속 64×32, 86.6%를 1·2순위로 처리하고 저속 8×16은 0.9%만 남긴다.
  • 실시간으로 못 쓰던 까닭: 정밀 온라인 솔버는 배치당 28.8 ~ 46.1초가 걸려 실전 서빙에 못 썼다. 반대로 배치 전에 틀을 고정해 버리는 정적 템플릿(비용 +38 ~ +98%)이나 구역별 행 패널 트리(+33 ~ +58%)는 품질이 무너졌다.
  • 해법 (사전 준비 표 + 경량 실시간 조립): 출석부가 32 / 256가지로 고정돼 있으므로, 모델 로드 때 딱 1회(13.1 ms, 시험 데이터 0건) 8개 구역별 비트맵과 이웃 순위표를 만들어 둔다. 매 배치에는 16스레드 CPU AVX2로 1.49 ~ 2.83 ms(46초 대비 16,000배 단축, 정밀 솔버와 칸 수 격차 단 0.22%p) 만에 타일 계획을 뽑아 어텐션 실행 뒤에 0.000 ms 노출로 숨긴다.

④학습과 타일링을 잇는 고리: 끝쪽 선택적 버퍼 1*

사후학습에서 중심점마다 자기 출석부 앞쪽에 에너지를 몰아 두면, 목록 끝쪽 소수 뉴런은 꺼도 정확도가 버티는 선택적 버퍼(1*, Don't-Care 자유도)가 생긴다. 솔버는 이 1*을 마지막에 버리는 후처리가 아니라 열·토큰·5단계 틀 크기 선택에 직접 반영한다. 기존 연구에 없는 두 번째 관찰이다.

  • 최종 모델은 1* = 0% (완전 무손실): BSMR · Fused3S · PIT에는 이런 1* 스위치 자체가 없다. 우리 구조는 필요할 때(예: 향후 대형 LLM에서 추가 압축이 필요할 때) 검증 문턱 기준으로 1* 비율을 열 수 있는 일반 구조를 갖추되, 최종 모델은 2순위의 가족·32열 블록 공유 사후학습만으로 이미 채움률 87.4%에 도달해 검증 문턱(90.96%) 기준으로 1* = 0%를 채택했다. 그 결과 단일(B = 1)과 대형 배치(B = 512 ~ 2,048)의 출력이 100% 일치하고 묶기 정확도 하락이 0.00%p다.

⑤실제 모델 스케일(4층 × 4,096 뉴런) 10회 반복 대조

공정성 원칙: 비교 대상인 MatFormer, 고전 1D SpMM, BSMR 전 버전에도 우리의 최종 희소 표(1* = 0%)와 OLO 행 정렬을 똑같이 제공했다. B = 2,048 독립 배치 10회 평균이다 (512열 구역, 4층 × 2,048 × 4,096, 활성 1 = 13.56%).

  • BSMR 5단계 행 패널 상한 대비: ×0을 60.9% 더 줄였고(5.14% → 2.01%), 채움률 72.5% → 87.1%, 실측 비용 1.16× 우위다.
  • BSMR 최강 OLO 16×16 대비: 총 틀 수 80.0% 감소(20,830 → 4,166틀), 실측 GPU 단가 비용 2.11× 우위다(36.8% → 17.4%).
2순위

패러다임 역전: 예측기 추종 → 선제 유한 차등 명단 × 하드웨어 친화 공유 사후학습

"원래 모델이 켜는 뉴런을 예측기가 뒤따라 맞힌다"는 전제를 뒤집어, 하드웨어가 묶기 좋은 규칙을 먼저 정하고 모델이 사후학습으로 거기에 맞춰 정확도를 지키게 했다.

왜 이 출발점 역전이 결정적인가1순위의 1.49 ~ 2.83 ms 실시간 비격자 타일링은 이 역전 위에서만 성립한다. 기존 문맥적 희소성 연구가 당연하게 깔고 있던 전제를 정반대로 뒤집었기 때문에 모든 톱니바퀴가 맞물렸다.

①출발점의 역전: 24096가지 대 고정 32 / 256가지

사후학습이 필수인 근거: 베이스 모델에서 출발하지 않고 처음부터 고르며 배우면, 같은 평균 활성률의 작은 밀집 모델보다도 정확도가 떨어졌다. 이미 모든 표현을 배운 베이스 모델을 들고 고정된 출석부 규칙에 맞춰 사후학습해야만 작은 밀집 모델을 크게 넘기며 정확도를 지킨다.

②중복 허용 가변 K 출석부 대 고정 전문가 분할 (MoEfication · CMoE · LTE · D2DMoE)

뉴런 8개(N1 ~ N8) 예시에서 비지도 좌표 구역 3개가 각각 아래 뉴런을 필요로 한다고 하자. N1은 전체 공용, N2는 A · B만 같이 쓰는 부분 공용, N5는 A 특화다.

  • 실제 1층 숫자 (4,096뉴런 · 32중심점): 겹침 없이 32개 방으로 쪼개면 중심점당 4,096 ÷ 32 = 128개(3.1%)가 한계다. 중복 허용 출석부 덕분에 1층 중심점 하나가 평균 약 900개(22.1%)를 자유롭게 공유해 정확도를 지키면서도, 4층 전체 평균은 13.52%로 압축된다.
  • AWC (Euro-Par 2025)와의 차이: AWC는 토큰이 켠 뉴런 무늬 자체를 코드북으로 묶고 "어느 코드북인지 100% 맞힌다"고 가정해, 실제 고르는 법·사후학습·배치 가속이 모두 없다. 우리는 뉴런 무늬가 아니라 층 입력 좌표를 중심점으로 묶어 단순 내적 1회로 바로 고른다.

③층별 차등 중심점 M = [32, 32, 32, 256]과 하드웨어 친화 공유 사후학습

단순히 중심점마다 제각각 앞쪽 뉴런만 몰면, 같은 가족에 속한 이웃 중심점끼리도 쓰는 뉴런이 흩어져 대형 배치에서 타일 안 ×0, 2단계 합집합, DRAM 읽기가 모두 커진다. 그래서 구조와 사후학습 손실 자체에 GPU 텐서 코어 타일 모양을 심었다.

구조

층별 차등 중심점 M = [32, 32, 32, 256]

연산 비중이 큰 앞 1 ~ 3층은 M = 32로 통합해, 배치가 512 → 1,024 → 2,048로 커질수록 같은 중심점에 속하는 토큰이 평균 16 → 32 → 64명으로 불어나며 쓰는 뉴런이 100% 겹친다(64×32 큰 틀의 뼈대). 출력 직전 4층은 M = 256으로 세밀하게 남겨 활성 뉴런을 0.80%까지 줄이고 정확도를 지킨다.

3순위

대형 배치 SwiGLU FFN의 토큰별 희소성 유지 (단일 · 서버 E2E 동시 실측)

배치 합집합으로 뭉개지 않고 토큰마다의 뉴런 집합을 유지한 채, 대형 배치 SwiGLU FFN 자체를 단일 요청과 서버 양쪽에서 실측 가속했다.

왜 3위인가여러 연구가 "대형 배치에서 뉴런 단위 FFN 희소성이 무너진다"고 비워 둔 자리이지만, 결과 주장의 최종 파급력은 향후 실제 사전학습 LLM 검증으로 확정되므로 3순위에 둔다.

①4 × 8 예시: 배치 합집합(100%로 꽉 참) 대 토큰별 집합 유지

배치에 토큰 4명(T1 ~ T4)이 들어왔고, 각 토큰은 8개 뉴런 가운데 딱 2개(25%)만 필요로 한다. T1 {N1, N2} · T2 {N3, N4} · T3 {N5, N6} · T4 {N7, N8}.

이 합집합이 100%로 꽉 차는 문제 때문에 Polar Sparsity(NeurIPS 2025)는 FFN 희소성을 ReLU 모델(OPT)의 소규모 합집합에만 적용했고, SwiGLU 대형 배치 FFN은 포기하고 어텐션 헤드 쪽으로 우회했다. Park 등(2026-05)도 큰 배치에서는 밀집 경로로 되돌아간다. 우리는 토큰별 뉴런 집합을 유지한 채 대형 배치 SwiGLU FFN 자체를 실측 가속했다.

②단일 요청(B = 1)과 대형 서버(B = 512 ~ 2,048) 동시 실측

하나의 학습된 모델(베이스 대비 99.77%(90.81%), 1* = 0%, 순수 bf16, 양자화 없음)이 개인 PC(B = 1, 메모리 바운드)와 대형 AI 서버(B = 512 ~ 2,048, 연산 바운드) 양쪽에서 모두 실측 가속을 낸다.

  • 번호표로 골라 읽으면서도 cuBLAS보다 빠른 까닭 (02 · 04 요약): ① 긁어 오는 단위가 숫자 1알(2B)이 아니라 2 ~ 8 KB의 긴 연속 막대기(캐시라인 16 ~ 64박스, 버리는 바이트 0%), ② 64×32 큰 틀로 한 번 긁어 와서 오래 연산해 긁어 오는 횟수를 4배 줄임, ③ 512열 구역(L2 스트립)으로 가중치를 L2 캐시에 상주시켜 DRAM 재읽기 0회.
  • 양자화와 직교: 위 수치는 전부 양자화 없는 순수 bf16 실측이므로, 향후 FP8 / INT4 양자화나 어텐션 가속 기법과 그대로 곱셈 결합이 가능하다.

③저·중·고 밀도 전 구간 가속 (밀도 무관성, PIT 대비)

PIT(SOSP 2023) 같은 기존 마이크로타일 SpMM 커널은 주로 수 % 이하의 초저밀도 구간을 겨냥하고 고정 1 제약 아래 동작한다. 우리 5단계 사다리는 고·중밀도(22%)에서는 64×32 · 32×32 위주로, 저·초저밀도(9.6% · 0.8%)에서는 32×16 · 16×16으로 자동 적응해 전 밀도 구간에서 일관되게 가속된다 (B = 2,048, d = 4,096 실측).
